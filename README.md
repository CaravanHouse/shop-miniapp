# Витрина магазина: Telegram Mini App

Каталог, корзина и оформление заказа внутри Telegram. Заказ приходит владельцу в бот, статус он меняет кнопками, а клиент получает уведомления.

**Что показывает клиенту:** готовый магазин в Telegram без установки приложения. Демо-каталог — цветочный магазин, легко заменить (`shared/products.ts`).

## Что внутри
- Главная кнопка Telegram (MainButton) ведёт по шагам: корзина, оформление, заказ. В обычном браузере её роль играет нижняя кнопка
- Сумму заказа считает сервер по своим ценам, из браузера принимаются только id товаров и количество
- Владелец: «Принять → Собираем → Передан курьеру → Выдан», при каждом шаге клиенту уходит сообщение
- Статусы может менять только чат владельца
- Бесплатная доставка от порога, самовывоз, комментарий к заказу
- `/orders` показывает активные заказы, `/my` показывает заказы клиента, `/id` помогает узнать id чата

## Запуск
```bash
npm install
cp .env.example .env     # BOT_TOKEN, WEBAPP_URL (https), OWNER_CHAT_ID
npm run build
npm start
```
Проверка интерфейса в браузере: `DEV_NO_AUTH=1`, затем `npm run dev:server` и `npm run dev:web`. Тесты: `npm test`.

> Хранилище JSON подходит для демо. Для продакшена замените на PostgreSQL. Онлайн-оплата (Click/Payme) в демо не подключена.

# Витрина магазина: Telegram Mini App

[![CI](https://github.com/CaravanHouse/shop-miniapp/actions/workflows/ci.yml/badge.svg)](https://github.com/CaravanHouse/shop-miniapp/actions/workflows/ci.yml)

Каталог, корзина и оформление заказа внутри Telegram. Заказ приходит владельцу в бот, статус он меняет кнопками, а клиент получает уведомления.

**Что показывает клиенту:** готовый магазин в Telegram без установки приложения. Демо-каталог — цветочный магазин, легко заменить (`shared/products.ts`).

## Что внутри
- Главная кнопка Telegram (MainButton) ведёт по шагам: корзина, оформление, заказ. В обычном браузере её роль играет нижняя кнопка
- Сумму заказа считает сервер по своим ценам, из браузера принимаются только id товаров и количество
- Владелец: «Принять → Собираем → Передан курьеру → Выдан», при каждом шаге клиенту уходит сообщение
- Статусы может менять только чат владельца
- Бесплатная доставка от порога, самовывоз, комментарий к заказу
- `/orders` показывает активные заказы, `/my` показывает заказы клиента, `/id` помогает узнать id чата

## Запуск
```bash
npm install
cp .env.example .env     # BOT_TOKEN, WEBAPP_URL (https), OWNER_CHAT_ID
npm run build
npm start
```
Проверка интерфейса в браузере: `DEV_NO_AUTH=1`, затем `npm run dev:server` и `npm run dev:web`. Тесты: `npm test`.

## Деплой на Railway
1. **New Project → Deploy from GitHub** → этот репозиторий. Команды сборки и запуска, health check (`/health`) и автоперезапуск уже описаны в `railway.json`.
2. **Подключите Volume** с путём `/data`. Без него заказы стираются при каждом деплое.
3. **Settings → Networking → Generate Domain**: получите публичный адрес.
4. **Variables:** `BOT_TOKEN`, `WEBAPP_URL` (адрес из шага 3, можно без `https://`), `OWNER_CHAT_ID` (напишите боту `/id`), `DATA_DIR=/data`. `PORT` Railway задаёт сам.
5. Оставьте **1 реплику**: данные лежат в JSON-файле, несколько копий сервера затрут друг друга.

`DEV_NO_AUTH=1` на Railway сервер не запустит: с ним любой может оформлять заказы от чужого имени без проверки Telegram. Для каждого проекта нужен **свой бот** в @BotFather: один токен в двух проектах даёт ошибку 409 Conflict.

## Данные
Заказы хранятся в JSON-файлах в папке `DATA_DIR` (по умолчанию `./data`). При большой нагрузке переходите на PostgreSQL.

> Онлайн-оплата (Click/Payme) в демо не подключена.
